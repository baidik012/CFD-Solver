## Requirements

### Python Libraries

The solver depends on Python 3.10+ and the following libraries:

- numpy>=1.24.0
- matplotlib>=3.7.0
- scipy>=1.10.0
- pytest>=8.0.0        # for running tests
- pandas>=2.1.0        # optional, for data handling
- numba>=0.58.0        # optional, for performance acceleration
- tqdm>=4.66.0         # optional, progress bars

Install all required packages using:

```bash
pip install -r requirements.txt
